# schemas/ (generated mirror)

`schemas/tools/<tool>.json` in this directory is a **byte-identical mirror** of
`src/http_semantics_mcp/schemas/tools/<tool>.json`.

Rules (plan/02 section 3):

- The package path is the **only editable source of truth**.
- This mirror is regenerated by `tools/gen_schemas.py` (M2+) and committed.
- A gate asserts byte equality per file, and that the file set matches.

The mirror is what the task document calls "the client-visible contract"; the
package path is what `tools/list` actually serves. Keeping both byte-identical
means the shipped contract cannot drift from the documented one.

Nothing is generated here yet: the five tool schemas land in **M5** together
with `tools/gen_schemas.py` (decision D43). M2's two CORS tools ship an inlined
`inputSchema` in `registry.py`, which is what `tools/list` serves today.
