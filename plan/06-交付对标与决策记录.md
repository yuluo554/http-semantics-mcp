### M4 新增（D47–D49）

| 编号 | 决策 | 弃选项 / 结论 | 弃因 |
| --- | --- | --- | --- |
| **D47** | T4 的三处边缘口径按"规范可直接推出 + 无 golden 覆盖"定案：①`*` 的语义绑定"当前表示是否带 ETag"——`If-Match: *` 在 `resource.etag` 为 `null` 时**失败**（412），`If-None-Match: *` 在同样情形下**不命中**（200）；②`If-Modified-Since` 只对 `GET`/`HEAD` 生效，在其它方法上整条条件**不评估**（`rule_applied = "none"`）；③`resource.etag` / `resource.last_modified` 在评估前**严格校验**（坏值 → `INVALID_HEADER_VALUE` / `INVALID_TIME_FORMAT`），而请求头里的日期非法只忽略该条件并在 `explain[]` 记 `COND_IGNORED_INVALID_DATE` | ①`*` 视为"资源总是存在"（无条件通过）；②把 `If-Modified-Since` 也用在写方法上；③把 `resource` 的坏日期也当成"忽略条件"（与 `cond-012` 同处理） | ①`resource.etag` 为 `null` 就是"没有当前表示可比"，此时 `*` 通过等于凭空发明一个表示；②`cond-018` 已把写方法上的判定交给 `If-Unmodified-Since`，把缓存验证器也接上会多出一个规范没定义的 304 面；③`resource` 是调用方提供的当前资源元数据（不是条件本身），`data/README.md` §4.4 明写"解析失败 → 结构化错误，**不做猜测性容错**"，"忽略"只适用于 RFC 9110 §13.1.3 明令忽略的**请求头**日期（`cond-012` 冻结的正是那一侧）；错误码取 §4.6 的既有映射（时间字面量 → `INVALID_TIME_FORMAT`，ETag → `INVALID_HEADER_VALUE`），不另造组合 |
| **D48** | T5 的两处边缘口径：①`Vary` 内的重复字段**只报一次**，取**源书写顺序里第一个**重复的字段（`Vary lists {header} more than once` 模板只点名一个字段）；②`Vary: *` **短路**在重复提示与逐字段比较之前，输出只有 `VARY_STAR_NEVER_MATCHES` | ①每个重复字段各报一条；②先报重复再短路 | ①模板只带一个 `{header}` 占位，逐字段报会把同一句文案重复成多条噪声；②`Vary: *` 已经把"永不命中"答完，再解释重复字段是把两个不同层级的结论混进同一个 `reasons[]`（`vary-003` 的期望只有 star 一条，短路位置是它的直接推论） |
| **D49** | 生产侧相对生成侧（oracle）的三处**有意偏差**，M5 若做双侧一致性扫描不得判为漂移：①T4/T5 把 `request_headers` / `resource` / `cached` / `incoming` 列为 `required` 并在缺失时报 `INVALID_INPUT`，oracle 对缺键按空对象兜底；②`resource.last_modified` 非法时生产侧按 §4.6 报 `INVALID_TIME_FORMAT`，oracle 报 `INVALID_INPUT`；③oracle 对**空数组**取首值时抛 `IndexError`，生产侧 `first_value` 按"没有该值"处理 | 生产侧照抄 oracle 的宽松兜底 / 照抄 oracle 的错误码 / 让生产侧同样抛异常 | ①`registry` 的 `required` 与 handler 的拒绝面必须一致（`test_registry.py::test_declared_required_fields_are_the_ones_the_handler_rejects`），声明必填却静默兜底是把 schema 当装饰；②`data/README.md` §4.6 已把"时间字面量不合 §4.4"固定映射到 `INVALID_TIME_FORMAT`（K9：§4 是唯一口径），oracle 在这一点上与自己处理 `resource.etag` 时选的 `INVALID_HEADER_VALUE` 也不自洽；③`IndexError` 不是任何契约里的错误形态（§4.6 只有五个 `error.code`），空数组在语义上就是"该 header 没有值"。三条都不落在任何冻结 golden 上（87 条逐字节相等不受影响） |
