# references (in-package source of truth)

`codes.json` lands here in M1, generated by `tools/gen_codes.py` from the
single definition in `data/README.md` section 4.1.

This directory is the **only editable source**; `references/codes.json` at the
repository root is a byte-identical mirror. The package copy is what an
installed distribution reads via `importlib.resources`; the root copy is what a
reader browsing GitHub sees. One file to edit, two places to read.

Shape (M1):

```json
{
  "version": 1,
  "codes": {
    "CORS_MISSING_ALLOW_ORIGIN": {
      "prefix": "CORS",
      "spec_ref": ["Fetch §CORS check"],
      "severity": "violation",
      "template": "..."
    }
  },
  "notes": {},
  "vary_normalization": {}
}
```

Rules enforced by gates:

- No `code` may appear here that is not in `data/README.md` section 4.1, and
  vice versa. The generator is the only writer; the table is the only input.
- No second copy of a `code` literal may exist in Python source outside this
  file's consumer layer.
